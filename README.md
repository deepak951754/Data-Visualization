# Data Visualization Project

A Python-based data visualization project that presents data using charts, graphs, and dashboards.

## Features
- Monthly sales bar chart
- Sales and profit trend analysis
- Sales vs. profit scatter plot
- Automatic data insights

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn

## Installation
```bash
pip install pandas matplotlib seaborn
```

## How to Run
```bash
python data_visualization.py
```

## Purpose
To visualize data, identify trends, and support better decision-making.
